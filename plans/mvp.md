> 状态：历史阶段的开发与首轮 Android 实拍记录。Expo / React Native 实现已退出当前工作树；本文的已完成项、依赖与验证命令只适用于当时版本。

## 1. 验证目标

验证用户能否选择一个内置构图模板，在真实相机画面上参考黄色引导线完成拍摄，并将照片可靠地保存到系统相册。

```text
选择模板 → 授权相机与照片写入 → 按引导构图 → 拍照并保存 → 继续拍摄或退出
```

MVP 到照片成功写入系统相册为止。拍摄后不进入单独的结果页，也不提供“重拍”和“完成”步骤；用户留在相机页即可继续拍摄。

## 2. 历史已完成范围

- 在应用代码中内置 `schemaVersion: 1` 的构图模板文档与多组 preset。
- 模板页展示 preset 名称、用途和视觉预览，并通过 `presetId` 进入相机。
- 在进入相机前依次检查并申请相机权限与照片写入权限。
- 权限被拒绝时停留在模板页；系统不允许再次询问时引导用户打开设置。
- 使用 Expo Camera `CameraView` 展示真实相机预览。
- 使用 React Native Skia 在预览上绘制黄色构图引导线和标注。
- 等待 `onCameraReady` 后才开放快门，并在拍摄期间锁定快门。
- 使用 `takePictureAsync()` 拍照，并通过 Expo MediaLibrary `Asset.create()` 保存到系统相册。
- 拍摄成功后更新相机页的最近照片缩略图。
- 支持前后镜头切换、闪光灯、缩放档位和双指捏合缩放。
- 支持打开系统相册。
- 构图引导层只存在于预览中，不写入最终照片。

## 3. 明确不包含

- 独立的照片结果页。
- 拍摄会话 `CaptureSessionProvider`。
- “重拍”和“完成”流程。
- 点击对焦、曝光补偿和实况照片。
- 用户手动裁切、滤镜和修图。
- 用户自定义或编辑模板。
- 网络请求、远程模板和后台管理。
- 登录、作品历史和本地数据库。
- AI 识别、实时调整提示和自动评分。

## 4. 模板与渲染边界

当时模板数据遵守 [旧模板数据结构](./template-data-model.md)，下列类型与容器已不再是当前格式：

- 顶层 `schemaVersion` 为 `1`。
- 用户选择 `CompositionPreset`，相机页读取对应 preset 的当前 variant。
- Element 的几何保存在 `shape` 中，坐标使用 `0...1` 的模板画布归一化值。
- 数据不保存颜色、线宽、屏幕像素或 Skia 运行时对象。
- 引导颜色和线宽由渲染代码统一控制。

Skia 构图层只负责把归一化 Shape 映射到当前预览视口。开放路径绘制线条，闭合路径、矩形和圆形只绘制轮廓，不填充或修改相机画面。

## 5. 页面流程

### 模板页

1. 从本地模板文档读取 presets。
2. 用户选择推荐模板或普通模板。
3. 顺序检查相机权限与照片写入权限。
4. 两项权限均可用后，携带 `presetId` 进入 `/camera`。

### 相机页

1. 根据路由参数查询 preset，并处理未知 `presetId`。
2. 启动 `CameraView`，在其上叠加透明 Skia Canvas。
3. 相机准备完成前禁用快门。
4. 用户可以切换镜头、闪光灯，通过按钮或双指手势缩放。
5. 点击快门后锁定拍摄，取得缓存照片并立即写入系统相册。
6. 保存成功后更新最近照片缩略图并继续停留在相机页。
7. 返回模板页时卸载相机预览。

## 6. 状态与异常处理

MVP 不引入第三方全局状态库。模板数据为随应用发布的只读数据，相机准备、拍摄、保存、镜头、闪光灯和缩放状态均由相机 feature 本地持有。

当前显式处理：

- 权限尚未决定、被拒绝或不能再次申请。
- preset ID 不存在。
- 相机挂载失败或尚未准备完成。
- 拍照返回空结果或抛出错误。
- 照片写入系统相册失败。
- 快速连续点击快门。

## 7. 完成标准

- 任意模板都能经过权限检查进入对应相机页。
- 相机预览、构图引导和标注正常显示。
- 引导线与相机预览使用同一构图区域，最终照片不包含引导线。
- 镜头切换、闪光灯、缩放按钮和双指缩放可用。
- 快速连续点击快门不会触发并发拍摄或崩溃。
- 拍摄状态和保存结果有明确反馈。
- 照片成功写入系统相册，并可通过相机页缩略图或系统相册查看。
- 权限拒绝、相机启动失败和保存失败不会造成黑屏或无响应。
- `npm run check` 与 Expo 配置检查通过。
- 至少在一台 iPhone 和一台 Android 真机走通完整流程。

当时记录的代码范围和首轮 Android 实拍验证已经完成。本文没有记录完整的 iOS 验收结果；该历史阶段的完成不等于当前原生 iOS 已完成同样的验收。
