## 首页

### 定位

首页帮助用户快速找到适合眼前拍摄对象的蒙版，并提供少量拍摄提示和模板灵感。首版没有 AI 推荐，重点通过清晰的入口、示例图和内容组织降低选择成本。

首批内容聚焦旅行与户外随拍，但展示文案不加入「旅途」「沿途」等限定词，避免让用户认为产品只适用于旅行。

### 内容顺序

首页从上到下分为三块：

1. **快捷入口**：首页的重点位置，帮助用户根据拍摄对象快速进入相机。
2. **简单 tips**：简短、容易执行的拍摄提示。
3. **分类模板推荐**：按分类展示推荐模板，供用户继续浏览和寻找灵感。

顶部侧重「现在要拍什么」，底部侧重通过模板示例寻找「想拍出的效果」。tips 暂不展开规划。

### 顶部快捷入口

采用四个入口：人物、风景、建筑、静物。当前文案方案使用「简短标题 + 一行说明」，配合直观的示例图表达拍摄范围。

区域引导语：**今天想拍什么？**

| 入口标题 | 辅助文案           |
| -------- | ------------------ |
| 拍人物   | 单人 · 合照        |
| 拍风景   | 山川 · 湖海 · 日落 |
| 拍建筑   | 街道 · 楼宇 · 地标 |
| 拍静物   | 美食 · 花草 · 小物 |

四个入口可以采用 2 × 2 图片卡片布局，具体尺寸与视觉样式尚未确定。

#### 分类与文案取舍

- 单人、双人和多人统一放入人物入口，双人不单独占据顶部位置。
- 「一个人」与「人和风景」存在重叠，不作为两个并列的顶部入口。
- 海边、湖边归入风景，不单独占据顶部位置。
- 展示名称使用「风景」而不是「山水」，以自然包含天空、草原等场景。
- 美食、花草和小物件归入静物；宠物不归入静物，首版暂不单设宠物入口。
- 分类不要求严格互斥，同一个蒙版可以用于多个分类。
- 使用直白、日常的表达，避免「道路纵深」等需要摄影知识才能理解的入口名称。
- 「拍静物」暂作为当前方案保留，通过辅助文案解释范围，后续可结合页面效果继续打磨。

#### 进入相机

点击快捷入口后直接进入相机，在相机底部左右滑动切换该分类相关的蒙版，结合真实取景画面进行选择。

大类入口仍需解决范围过宽的问题：每类应提供少量适用的蒙版，避免用户进入后反复跳过不相关选项。每类的具体蒙版、默认项、排序，以及人物中单人和合照的区分方式尚未确定。

### 底部模板推荐

底部作为次一级推荐区域，供用户通过成片预览寻找喜欢的拍摄效果。

#### 展示形式

- 每组采用「一句简洁标题 + 一组可横向滑动的预览图卡片」。
- 用户纵向浏览不同主题，横向滑动查看同一主题下的模板。
- 每张卡片对应一条组合了模板的业务内容，以成片预览图为主，可配简短名称；数据关系见下文。
- 露出下一张卡片的一部分，提示用户可以继续滑动。
- 同一组的预览图应展示可辨认的构图差异，帮助用户比较和选择。

#### 主题与顺序

当前确定的标题及从上到下的顺序：

1. **在风景里留个影**
2. **走到街角，拍一张**
3. **记录喜欢的事物**
4. **遇到好看的天空**

其中「遇到好看的天空」降低展示优先级，放在最后一组。各组的具体模板、卡片数量和点击后的路径留待后续讨论。

## 模板

### 定位

让用户按自己的拍摄意图浏览和查找完整的模板库，通过成片示例比较具体模板的效果。

### 页面结构

页面从上到下分为三块：

1. **搜索框**：支持按拍摄对象或场景查找模板，例如「合照」「日落」「美食」。
2. **分类切换**：提供「全部 / 人物 / 风景 / 建筑 / 静物」，与首页使用相同的分类体系。
3. **模板预览区**：直接展示当前分类下的模板，以成片示例为主，方便浏览与比较。

初期采用「大类 + 模板列表」，切换分类后直接查看模板，不额外增加分类目录页或二级分类。后续只有当某类模板较多、已经影响查找效率时，再考虑增加细分。

## 本地数据组织

### 纯模板数据

模板数据单独维护，只描述构图结构，例如模板 ID、几何结构和构图参数。数据保持可序列化，独立于 Skia 运行时对象和屏幕像素值。

模板本身不决定拍什么，不包含人物、风景等分类，也不负责定义用途、面向用户的展示名称、示例图或拍摄提示。

### 业务数据与模板组合

业务数据维护拍摄内容的关键信息，并通过模板 ID 引用纯模板数据。两者组合后，形成用户浏览、搜索和选择的内容。

```text
纯模板数据
├── 模板 ID
├── 几何结构
└── 构图参数

业务数据
├── 展示名称
├── 分类与适用场景
├── 示例图、拍摄提示等关键信息
└── 引用模板 ID → 纯模板数据
```

同一份纯模板可以被多条业务数据引用，分别组合成人物、风景或静物等拍摄内容；蒙版结构只维护一份，拍摄语义由业务数据赋予。

首页入口、推荐分组和模板 Tab 围绕这些业务内容组织展示；进入相机时，根据引用的模板数据提供蒙版结构。文中页面层面所说的「模板」，指的是面向用户的组合内容。

当前先确定数据职责与引用关系，具体字段和本地文件组织方式留待实现时细化。
