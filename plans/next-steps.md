- 真机核对[搜索列表](../ios/Framewise/Features/Search/SearchView.swift)、[模板卡片](../ios/Framewise/Features/Search/SearchTemplateCard.swift)与[瀑布流布局](../ios/Framewise/Features/Search/SearchTemplateLayout.swift)的 3:4、1:1、16:9、9:16、4:3 混排时卡片整体比例、间距、滚动与点击进入相机；当前模板封面仍为色块占位，标题与默认变体推荐比例叠加在封面内，核对较矮卡片的紧凑排版与浅色半透明底的可读性。

## 待优化：内容、体验与测量

- 按场景、主体与拍摄条件组织少量有效模板，改善文案、首屏顺序和同组差异；落实[产品 V1](product-v1.md)与[页面草案](app-structure.md)中仍适用的选择原则。
- 依据[外拍观察](field-validation-2026-09-05.md)和[蒙版验证方案](mask-validation.md)补充同场景无蒙版对照、完成构图耗时和用户反馈，复查中心主体、水面倒影、前景纵深等模板的适用条件。
- 若实际使用仍明显受保存等待影响，先建立独立 Release 基线：冷 / 热启动、首张 / 后续张、Live 开关与切镜、交付 / 加工 / 写库、峰值内存和发热。确认瓶颈后再做最小实验，不以降低画质换取未经确认的收益。
- 快门遮罩与 readiness、连续拍摄、非零曝光提示和对焦复位的手感按真机反馈调整；已实现机制不等于用户体验目标已通过。

2026-09-28 首拍调查已结束；串行处理实验撤回，尚无进一步优化结论。只在真实影响或新测量证据出现时重启调查，详见[相机实验记录](camera-experiments.md)。

- 账号、社区、云同步、商业化套餐、模板远程更新 / 缓存：非当前执行范围。
- 最近使用、收藏、自定义模板、Template Studio 编辑 / 写回：没有当前实现或既定实施排期，需根据真实需求决定。
