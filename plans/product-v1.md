# Framewise 产品 V1 范围

> 状态：当前产品方向与验收目标；不是完成清单。核对日期：2026-09-28。
>
> 当前工程以原生 iOS 为主，UI 使用 SwiftUI，相机使用 AVFoundation。Expo / React Native、Android 原生相机探索和早期 SwiftUI 相机均属于历史阶段，不计入当前能力。
> 已实现功能集中在 [当前状态](./current-status.md)，未实现、待优化与待验证事项集中在 [后续工作](./next-steps.md)。

## 1. V1 目标

Framewise V1 解决两个问题：

1. 用户能否通过可靠、顺畅的原生相机完成拍摄。
2. 用户能否在没有 AI 辅助的情况下，找到适合当前场景的构图模板。

```text
选择构图模板 → 进入原生相机 → 参考蒙版调整取景
  → 拍摄并保存到系统相册 → 继续拍摄或返回选模板
```

这条流程是否稳定、清楚并能交给真实用户使用，是 V1 的完成依据。功能在代码中存在、构建通过、单次实验成功与产品验收完成分别记录。

## 3. 原生相机优先级

原生相机是产品核心。新相机已建立拍摄与保存闭环，下一步集中验证和打磨。

- 启动、退出、前后台切换、会话中断和恢复稳定。
- 预览、蒙版、点击对焦位置、设备方向与最终成片保持一致。
- 只展示设备支持的镜头、缩放、闪光灯和 Live Photo 能力；不可用时明确降级。
- 点击对焦、测光、曝光补偿、缩放和镜头切换在真机上符合预期。
- 静态照片与 Live Photo 的方向、裁切、镜像、水印、画质和相册配对正确。
- 快门反馈清楚，捕获与后台处理不会无谓阻碍继续拍摄。
- 捕获失败和保存失败可以被用户理解，不出现无提示丢失或假成功。

具体设计与已确认取舍见 [新相机架构](./ios-camera-architecture-v2.md)。性能、HEIF 和首拍等实验结果保留为独立记录，其设备与样本限制不得省略。

## 4. 无 AI 模板选择

模板选择的目标是降低理解成本与选择时间。V1 优先利用内容和清晰路径，不建设本地或云端模型、embedding、向量检索或自动评分。

- 使用真实、易辨认的成片表达模板效果，避免以几何缩略图代替实际使用条件。
- 按人物、风景、建筑、静物等用户拍摄意图缩小范围，再比较少量模板。
- 首屏突出差异明确、实拍有方向性支持的内容，不以模板数量作为完成标准。
- 提供易懂名称、适用场景、可执行提示及画幅说明。
- 用户发现模板不适合时，能够低成本返回或切换。
- 只有观察到真实需求时，再增加收藏、最近使用等能力。

[2026-09-05 实拍记录](./field-validation-2026-09-05.md) 支持继续探索静态蒙版，但缺少无蒙版对照，不能直接证明改善幅度。[应用骨架](./app-structure.md) 保留分类与首页的产品草案；它描述的完整交互仍未全部实现。

## 5. 实施与收尾顺序

1. 完成当前相机的真机稳定性、成片一致性和性能验证，处理影响拍摄闭环的问题。
2. 准备首批真实示例与模板使用条件，确定分类集合和默认排序。
3. 接通首页场景入口与推荐内容，完善模板查找和比较路径。
4. 进行新用户任务观察与有对照的蒙版实拍验证，再决定几何和内容调整。
5. 核对可访问性、本地化、权限文案和正式设置，完成交付验收。

待办只在 [后续工作](./next-steps.md) 维护状态，本文件保留产品范围与优先级，避免重复清单互相漂移。

## 6. V1 不包含的扩展方向

- 本地 AI、云端 AI、实时场景识别、自动模板推荐、评分和自动拍摄。
- 用户账号、云同步、社区、远程模板后台或大规模内容平台。
- 用户自定义 / 编辑模板、滤镜、完整修图与独立照片资产库。
- 视频拍摄、RAW、手动 ISO / 快门 / 白平衡、峰值对焦与直方图。
- Android 迁移或双平台验收作为当前 iOS V1 的完成门槛。

当前已有的 iOS Live Photo 属于相机能力，不能因为早期计划未纳入而误标为未实现。Android 专属资源保留在 `android/`，不代表当前存在可运行的 Android 应用。

## 7. 验收目标

### 相机与输出

- 用户可完成授权、预览、调整、拍摄、保存和退出。
- 连续拍摄、退出重进、前后台切换、中断与恢复不造成黑屏、崩溃或持续占用。
- 蒙版、对焦位置与成片没有明显错位；方向、镜像、画幅、质量和 Live Photo 配对正确。
- 不支持的能力自然降级，权限与保存失败有明确反馈。
- 多设备验证包含目标设备、系统版本、拍摄组合与失败结果，不以一次成功代替完整验收。

### 模板与产品流程

- 新用户无需理解专业术语，可根据示例和场景说明选择并使用模板。
- 首屏信息不会造成明显选择困难，选错模板时能够顺畅调整。
- 主要展示模板有真实示例、明确适用条件和可执行提示。
- 核心拍摄流程不依赖 AI、登录或网络；展示图片的当前远程示例需在正式内容落地时处理。
- 完成 `AGENTS.md` 规定的 iOS 构建检查与真机验收；Expo 的 `npm run check` 不再是 iOS 验收命令。

V1 达到这些目标后，再依据真实使用反馈决定继续相机优化、扩展模板内容或重新评估其他方向。
